# ATS Tasknera

Full-stack project structured with frontend and backend services.

## Project Structure

```
ATS_Tasknera/
├── frontend/     # Next.js 15 TypeScript application
└── backend/      # Node.js Express TypeScript API server
```

## Getting Started

### Frontend

```bash
cd frontend
npm run dev
```

Runs the Next.js app on [http://localhost:4028](http://localhost:4028).

### Backend

```bash
cd backend
npm install
npm run dev
```

Runs the Express backend server on [http://localhost:5000](http://localhost:5000).

### Root Commands

From the project root:
- `npm run dev:frontend` - Start the frontend app
- `npm run dev:backend` - Start the backend server
- `npm run install:backend` - Install backend dependencies
